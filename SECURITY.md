# Security Policy

## Scope & MVP Notice

**Passie is an open-source hobby project.**
The MVP operates in a trusted friend-group context and **does not feature cryptographically verified authentication or role-based access control**. Anyone with access to the deployed URL may select any member profile from the `/wie-ben-jij` picker.

Do not use Passie to store sensitive personal information, payment credentials, or confidential communications.

## Reporting a Vulnerability

If you discover a security vulnerability (such as a database injection, remote code execution, server-side request forgery, or credential leak) in the application code or deployment scripts:

1. **Do not open a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the project maintainers directly.
3. Include detailed steps to reproduce the issue and the potential impact.

We will acknowledge reports promptly and coordinate a fix before public disclosure.
